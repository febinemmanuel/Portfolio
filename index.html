computer_vision 0.95

Helmet & Rider-Safety Violation Detection with Analytics

Python, Ultralytics YOLOv8, OpenCV, PyTorch, Streamlit, Plotly, Pandas

Road safety enforcement on Kerala’s dense two-wheeler traffic needs more than image classification. This system detects riders and pillion passengers without helmets in real time and logs each violation for analysis.

  • Fine-tuned YOLOv8 on a Google Colab GPU with augmentation (mosaic, rotation, brightness); benchmarked mAP@0.5, mAP@0.5:0.95, precision, recall and a per-class confusion matrix.
  • Built a Streamlit app for uploaded video and live webcam inference, with confidence and IoU sliders to trade false positives against missed detections.
  • Created an exportable violation event log and a trends dashboard showing peak violation hours and daily compliance rates.
  • Designed privacy-safe reports that never store number plates or faces.
generative_ai 0.94

AI-Powered Brand-Aware Clothing Customization System

React, Node.js/Express, PostgreSQL with pgvector, Prisma, Gemini API, Cloudflare Workers AI, Docker

Sizes differ between brands, and most shops can’t reconcile your measurements, or the size you wear elsewhere, with a brand you’ve never tried. This platform lets users describe a garment in plain language and get a brand-accurate size recommendation.

  • Built a RAG pipeline: Gemini embeddings with pgvector similarity search over brand size-chart documents.
  • Wrote a deterministic Size Engine that scores every size against chest, waist, hip, shoulder, sleeve, inseam and rise, and flags likely alterations.
  • Added an LLM prompt parser with a rule-based NLP fallback, and reference-guided image generation so users can see the customized garment.
  • Packaged the services with Docker Compose and tracked the work on a JIRA board.
